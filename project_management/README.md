# Project management

Approach: short iterations driven by a Kanban board (To do / Doing /
Review / Done), one feature branch per task, peer review of every
merge, and a weekly check of progress against the plan.

| Document | Content |
|---|---|
| [timeline.md](timeline.md) | planned phases vs. actual progress |
| [risk_analysis.md](risk_analysis.md) | risks and mitigations |
| [team_organization.md](team_organization.md) | roles, decisions, issue handling |
| [acceptance_tests.md](acceptance_tests.md) | features tested, bugs found/fixed |
| [blocking_points.md](blocking_points.md) | blockers and conflicts |

Fill the `TODO` fields with your real dates, names and results: this
folder must reflect what really happened.
